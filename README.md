# MyShop — Django E-Commerce with Star Rating

Full-stack e-commerce built with Django featuring product catalog, user auth, and a real-world star rating system (one review per user per product).

## Features
- Custom user model with email uniqueness
- Category & Product management
- Star rating 1–5 with unique constraint per user
- Average rating & rating distribution
- Review create / update / delete
- Bootstrap 5 responsive UI
- Environment-split settings (base / development / production)
- Deployment-ready for Render

## Tech Stack
Django 5 · PostgreSQL (prod) / SQLite (dev) · Bootstrap 5 · WhiteNoise · Gunicorn
